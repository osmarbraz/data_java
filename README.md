# Programa Data

Faça um programa orientado a objetos para manipular o tempo de um relógio. A classe possui 3 atributos do tipo inteiro(int) chamados hora, minuto e segundo.

a) Analise o contexto e faça as abstrações necessárias para obter os atributos principais;

b) Crie a estrutura de pacotes; 

c) Adicione os atributos e métodos get's set's; 

d) Adicione os construtores desta classe; 

e) Crie um método para solicitar o dia, o mês e o ano para o usuário.

f) Crie um método para validar os dados que estão sendo atualizados.

g) Crie um método para incrementar para o próximo dia.

h) Crie um método para incrementar para o próximo mês.

i) Crie um método para incrementar para o próximo ano.

j) Crie um método para decrementar para o próximo dia.

k) Crie um método para decrementar para o próximo mês.

l) Crie um método para decrementar para o próximo ano.

m) Crie um método para retornar a data como string(dd/mm/aaaa).

n) Crie um método para imprimir a hora no formato dd/mm/aaaa.

o) Crie um método para retornar  verdadeiro ou falso se o ano da data é bissexto ou não. Um ano é bissexto se for divisível por 4, mas não por 100. Um ano também é bissexto se for divisível por 400.

p) Crie um método que receba o número do mês como argumento e retorne o total de dias do ano até aquele mês.

q) Crie um método sobrecarregada que receba como argumento e o nome do mês em vez do número dele e retorne o mesmo total de dias.

r) Crie um método para adicionar dois objetos da classe data passados como argumentos.

s) Crie um método que subtraia duas datas e retorne o número de dias entre elas. A função recebe dois objetos da classe data passados como argumentos.

u) Na Classe principal (main class) instancie um objeto da classe Tempo e faça a entrada de dados e saída dos dados para testar todos os métodos criados através de um menu.

Desenvolvido utilizado JDK 1.8 e NetBeans 13
